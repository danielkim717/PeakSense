# 제출 당시 집계 결과

이 폴더는 최종 코드 묶음에 들어 있던 JSON 집계 파일을 그대로 보존합니다. 새 실험은 `outputs/results/`에 저장되므로 이 파일들을 덮어쓰지 않습니다.

| 파일 | 내용 |
|---|---|
| `ch2_main.json` | 주 모델 비교, 입력·구조 비교, 상태 분류, 15분 예측 |
| `ch2_gru.json` | 1,728시간 공통 표본에서 GRU 비교 |
| `ch2_robustness.json` | 주별 성능, 기준값 민감도, 예측구간·경보 등 |
| `ch3.json` | 피크 조건, SHAP, 오류·경보별 분석 |
| `ext_model.json` | 추가 모델·예측구간 탐색 결과 |
| `ext_schedule.json` | 생산일정 후보 탐색 시뮬레이션 |

**예측구간·경보·일정 저감률에는 재검증 사항이 있습니다.** 원본 파일의 수치를 보존하는 것과 해당 수치가 검증 완료된 운영 성능이라는 주장은 다릅니다. [검증 범위](../../docs/LIMITATIONS.md)를 확인하세요. 시간별 실제값·예측값 CSV는 데이터 재배포 범위를 줄이기 위해 포함하지 않습니다.
