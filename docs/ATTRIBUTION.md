# 출처와 이용 범위

## 프로젝트

제6회 K-인공지능 제조데이터 분석 경진대회, 「제조 생산데이터 기반 전력사용량 예측 및 최대피크 위험조건 분석」. 광운대학교 전자통신공학과 강기택·김태우·신여진의 프로젝트입니다.

설명 문서는 최종 `KAMP 공모전 발표자료.pdf` 30장과 결과보고서를 참고했습니다. 사용자의 요청에 따라 발표자료 파일은 공개하지 않으며 보고서 원본도 저장소에 포함하지 않습니다. 진행 내용과 결과는 Markdown 문서로 정리했습니다.

코드는 최종 버전으로 제공된 `PeakSense_code.zip`의 01~09 단계입니다. 이전 버전 `PeakSense_AI.zip`은 사용하지 않았습니다. 최종 발표자료의 통합 엔진과 제공 코드의 확인 범위는 [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md)에 표시했습니다.

## 코드·문서의 공개 범위

코드·문서에는 현재 별도의 오픈소스 라이선스를 지정하지 않았습니다. 공개 저장소라는 이유만으로 원본 데이터나 코드·문서에 대한 자유로운 재배포 권한이 부여되는 것은 아닙니다. 데이터 권리와 프로젝트 코드·문서 권리는 구별됩니다.
