# 검증 범위와 개선 과제

이 저장소는 공모전 최종 제출 자료를 보존하고 설명하기 위한 기록입니다. 아래 항목은 코드 대조에서 확인한 사항으로, 문제를 수정하고 해당 실험을 다시 평가하기 전까지 관련 지표를 운영 성능으로 보장하지 않습니다. 제출 당시 코드를 보존했으며 발표자료·보고서 원본은 업로드하지 않습니다.

## 입력의 가용 시점

현재 실험은 제공된 생산 기록을 사전에 주어진 생산계획으로 간주합니다. 또한 관측 기상을 예보의 대용으로 사용합니다. 배포 시에는 예측 시점에 실제로 확보된 생산계획·기상예보와 변경 이력을 사용해야 합니다. 기존 실험은 실제 예보 오차까지 포함한 운영 평가가 아닙니다.

주별 재학습과 전일 입력 가정을 함께 사용하므로, 주간 결과를 ‘일주일 전체를 첫날에 확정 예측한 성능’으로 표현하지 않습니다. 전후 계획 특성과 결측 풍속 보간의 입력 시점도 함께 감사해야 합니다.

## 학습 마감 시각 설명

`src/config.py`의 `ISSUE_HOUR=11`과 `src/evaluate.py`의 `index < issue`가 결합되어 전날 10시 행까지 학습에 포함됩니다. 보고서의 ‘전날 12시에 11시 관측까지 사용’과 다릅니다. 제공 코드의 결과를 보존하기 위해 현재 상수를 바꾸지 않았습니다. 후속 버전에서는 관측 구간의 시작·종료 시각 정의를 먼저 확정하고 코드·문서·평가를 함께 맞춰야 합니다.

## 예측구간과 경보의 잔차 경계

`02_robustness.py`에서 `W-WED` 주기 기준으로 과거 잔차를 모으면, 목요일 예측의 전날 정오 이후에 생기는 수요일 잔차가 포함될 수 있습니다. 예를 들어 7월 1일 예측 시점이 6월 30일 정오라면 6월 30일 23시의 잔차는 아직 알 수 없습니다.

따라서 제출 당시의 예측구간 적중률 84.1%, 경보 재현율 89.6%·정밀도 51.2%, 이를 바탕으로 한 경보별 분석은 시간 경계를 바로잡아 재평가해야 합니다. 이 항목은 **잔차를 이용한 예측구간·경보 평가에 관한 문제**이며, 저장된 시간 최대수요 점 예측 MAE 7.25의 산술 재계산과는 구별됩니다. 점 예측 역시 앞서 설명한 계획·기상 가정을 전제로 합니다.

## 생산일정 후보 탐색

`src/scheduler.py`에서 확인한 개선 과제입니다.

- 인건비 정규화의 분모가 후보별 합이 아니라 후보 묶음 전체 합을 참조해, 같은 후보라도 함께 비교하는 후보 수에 따라 목적함수 값이 달라질 수 있다.
- 각 탐색 단계의 이동 거리를 ±2시간으로 제한해도 여러 번 이동하면 원래 시각에서 2시간보다 멀리 갈 수 있다. 전체 이동 제한이 필요하면 원래 계획을 기준으로 추적해야 한다.
- 목적함수는 상위 전력값을 함께 반영하므로 최대값 하나만을 최소화하는 문제와 다르다. 국소 탐색이 전역 최적해를 보장하지도 않는다.
- 실제 설비별 용량·작업 순서·품목 전환·납기·교대 제약을 모두 담은 공정 스케줄러는 아니다.

제출 당시의 위험일 예측 최대수요 2.3% 감소는 현재 구현 아래 계산한 시뮬레이션 결과입니다. 목적함수와 제약을 고친 뒤 다시 계산해야 하며, 실제 현장 저감 성과로 제시하지 않습니다. 예측 모델의 입력 생산량을 바꾼 결과는 인과적 효과나 실제 생산 가능성을 보장하지 않습니다.

## 추가 모델·일반화

PeakSense+는 평가 구간의 오류분석을 바탕으로 고안된 후속 모델입니다. 같은 구간에서 나온 개선량은 탐색 결과로 보고, 새로운 기간이나 다른 공장에서 검증해야 합니다. 단일 공장·약 8.5개월 자료와 반복 전력 패턴도 일반화의 한계입니다.

## 단위와 이용 범위

원자료 전력값의 물리 단위와 집계 정의가 확정되지 않았습니다. 스크립트의 ‘구간 총 사용량’이나 그래프 숫자를 근거 없이 kWh, 전기요금 절감액, 탄소 절감량으로 해석하지 않습니다. 187은 분석 기준이며 계약전력 한계가 아닙니다.

## 후속 검증 순서

1. 실제 생산계획·기상예보의 생성 시점과 관측 시각 정의를 확정한다.
2. 학습·잔차의 시간 경계와 일정 목적함수·누적 이동 제약을 수정한다.
3. 기존 실험을 다시 실행해 수정 전후 결과를 별도 버전으로 남긴다.
4. 새로운 기간에서 예측오차·피크 누락·경보 부담을 평가한다.
5. 설비 제약을 반영한 일정안을 현장에서 검토하고 실제 효과를 확인한다.
