# 미래 생산계획 CSV 작성법

[plan_template.csv](../plan_template.csv)는 원본 자료 이후 날짜를 예측할 때 넣는 예시 양식입니다. 예시 숫자를 실제 생산계획과 기상예보로 바꾸어 사용합니다. 한 행은 한 시간이며, 이 파일의 값 자체가 공장의 미래 실적을 뜻하지 않습니다.

| 열 | 의미 | 예시와 작성 기준 |
|---|---|---|
| 일시 | 예측할 시간의 시작 시각 | `2021-09-15 08:00`; 시간순으로 중복 없이 작성 |
| 생산량 | 그 시간에 생산할 계획량 | `1200`; 원자료와 같은 단위, 비생산 계획이면 `0` |
| 기온 | 예측 시점에 확보한 기온 예보 | `26.0`; 섭씨 |
| 풍속 | 풍속 예보 | `1.8`; 원자료와 같은 단위 |
| 습도 | 습도 예보 | `70`; 원자료와 같은 척도 |
| 강수량 | 강수량 예보 | `0.0`; 원자료와 같은 단위 |
| 인건비 | 해당 시간의 비용 배율 | 코드에서 사용하는 주간 `1.0`, 야간·휴일 `1.5` 기준 확인 |

## 작성 예시

아래 한 행은 형식 설명용입니다. 하루 예측에는 그날의 시간별 계획과 필요한 전후 계획을 준비합니다.

```csv
일시,생산량,기온,풍속,습도,강수량,인건비
2021-09-15 08:00,1200,26.0,1.8,70,0.0,1.0
```

```bash
python 06_predict.py --start "2021-09-15 00:00" --end "2021-09-15 23:45" --plan plan_template.csv
python 09_tomorrow_preview.py --day 2021-09-15 --plan plan_template.csv
```

06은 지정 구간의 예측을 CSV·그림으로 만들고, 09는 위험시간·생산일정 후보를 함께 보여줍니다. 각 실행은 원본 과거 자료를 읽어 학습하므로 이 양식만으로 실행되지는 않습니다.

## 입력을 준비할 때

- 미래 전력값이나 `공장인원`은 작성하지 않습니다. 전력은 모델이 예측할 값입니다.
- 앞뒤 생산량·연속 생산시간·종료 시각 특성이 있어, 예측할 시간만 떼어 넣는 것보다 확정된 전후 계획을 함께 준비하는 것이 좋습니다. 없는 계획이 실제로 0인 것처럼 해석되는 경계는 검토해야 합니다.
- 현재 로더는 원본 시간축과 겹치는 계획 행을 제거합니다. 과거 생산기록의 수정이나 과거 누락 시간 보충용 양식으로 사용하지 않습니다.
- 저장된 실험은 생산기록을 계획으로, 관측 기상을 예보로 간주했습니다. 실제 운영에서는 예측 당시 확보된 값으로 평가해야 합니다.
