# 모델과 입력

## 예측 문제

핵심 모델은 생산계획·달력·기상을 이용해 다음 날 각 시간의 최대수요를 예측하는 회귀모델입니다. 학습 정답은 해당 시간의 네 15분 전력값 중 최댓값입니다. 최종 입력 순서는 `final_features()`가 반환하며 저장 결과의 `features`에도 기록되어 있습니다.

| 입력 묶음 | 이름 | 의미 |
|---|---|---|
| 달력 5개 | `hour, dow, sunday, saturday, 인건비` | 시각·요일·주말·비용 배율 |
| 생산량 3개 | `prod, prod_log, run` | 계획량, log(1+계획량), 계획량이 양수인지 |
| 주변 계획 4개 | `prod_prev1, prod_next1, prod_prev2, prod_next2` | 앞뒤 1·2시간 계획량 |
| 생산 전환 2개 | `startup, shutdown` | 생산계획이 0에서 양수 또는 양수에서 0으로 전환 |
| 연속성 3개 | `run_streak, idle_streak, hours_to_stop` | 연속 생산·비생산 시간, 종료까지 남은 시간(최대 72) |
| 계획 규모 3개 | `prod_day_total, run_day_hours, prod_roll3` | 하루 총량·생산 시간 수·주변 3시간 합 |
| 기상 6개 | `기온, 풍속, 습도, 강수량, cdd, hdd` | 관측 기상 4개와 `max(기온−24,0)`, `max(5−기온,0)` |

다음 시간 계획을 참조하는 변수는 미래 실적을 미리 읽어도 된다는 뜻이 아닙니다. 실제 예측 시점에 다음 날 계획과 필요한 전후 구간 계획이 제공되어야 합니다. 공급되지 않은 계획 경계는 코드에서 0 또는 잘린 구간으로 처리될 수 있어 배포 전 경계 동작도 확인해야 합니다.

## 두 단계 상태별 예측

1. **상태 분류:** 과거 정답 `peak > 70`을 높은 부하 상태 1로 정의해 LightGBM 분류기를 학습한다.
2. **상태별 회귀:** 높은 부하와 낮은 부하 자료로 각각 LightGBM 회귀기를 학습한다.
3. **미래 예측:** 분류기가 낸 높은 부하 확률이 0.5 이상이면 높은 부하 회귀기, 아니면 낮은 부하 회귀기의 결과를 사용한다.

`run`은 **생산계획 > 0인 입력 변수**, 상태 분류 정답은 **과거 전력 > 70인 학습 라벨**입니다. 둘은 다릅니다. 187은 고전력 사례 분석에 쓰는 별도 기준이며 계약전력이나 법적 기준이 아닙니다.

[`src/models.py`](../src/models.py)에 구조가, [`src/config.py`](../src/config.py)에 설정이 있습니다. 기본 설정은 트리 300개, 학습률 0.05, leaf 31개, 최소 leaf 표본 15개, 행·열 표본 비율 0.8, L2=1, random_state=0입니다. 회귀 설정은 제공 코드의 Huber 손실 설정을 보존했습니다.

## 평가 설계

테스트는 2021.7.1–9.14를 7일씩 나눈 11개 구간입니다. 각 구간 시작 이전의 자료로 학습한 뒤 해당 구간을 예측합니다. 주 평가 대상은 동일한 1,759시간·74일입니다. GRU는 시퀀스 준비가 가능한 공통 **1,728시간**에서 비교합니다.

코드의 실제 학습 조건은 `index < issue`이며 `ISSUE_HOUR=11`입니다. 첫 구간의 학습 자료는 2021.6.30 10시 행까지 포함됩니다. 보고서의 ‘전날 12시, 11시 관측까지’라는 설명과 한 시간 차이가 있으므로 재현 시에는 현재 코드 조건을 기준으로 합니다. [수정 및 재검증 사항](LIMITATIONS.md)

## 15분 예측과 운영 확장

- **다음 날 15분 예측:** 26개 입력에 15분 구간 번호를 더해 하루 96구간을 예측한다.
- **당일 갱신:** 최근 관측 오차로 예측값을 보정한다. 보정 설정은 7월 자료로 결정하고 8.1–9.14에서 평가했다.
- **생산일정 후보:** 하루 목표량을 유지하며 기존 생산 시간에 생산량을 재배분하고, 후보별 예상 피크를 비교한다. 전역 최적해나 실제 저감 효과가 보장되는 도구는 아니다.
- **추가 모델·예측구간:** PeakSense+와 적응형 예측구간은 후속 실험이다. 원래 평가 구간의 오류분석을 활용한 개발이므로 독립된 새 기간에서 재평가해야 한다.
