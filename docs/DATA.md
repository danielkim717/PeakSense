# 데이터와 전처리

## 무엇을 기록한 자료인가?

KAMP 가이드북에 따르면 선박 엔진용 볼트·너트 제조공장의 변압기 센서 전력, ERP 생산 정보, 기상 정보를 결합한 자료입니다. 공장 전체 관측값이므로 특정 설비가 켜졌는지, 불량품을 생산했는지, 어떤 설비가 피크의 원인인지를 이 자료만으로 확정할 수는 없습니다.

원본은 2021.1.1–9.14의 6,168행·18열입니다. 가이드북과 분석에 사용한 열 이름이 일부 다르며, 코드는 `공장직원`을 `공장인원`으로 통일합니다. 파일명의 `augumented`만으로 구체적인 증강 방법을 추정하지 않습니다.

| 변수 | 의미 | 모델에서의 처리 |
|---|---|---|
| 날짜·시간 | 공장 운영 날짜와 시간 | 시간 인덱스 및 달력 변수 생성 |
| 15분·30분·45분·60분 | 해당 시간의 0–15·15–30·30–45·45–60분 전력값 | 학습 정답과 15분 예측에 사용 |
| 평균 | 네 전력값의 평균 | 미래 구간 입력에서 제외 |
| 생산량 | 가이드북상 해당 시점에 생산해야 할 생산량 | 사전 생산계획으로 확보된다는 가정 아래 입력 |
| 기온·풍속·습도·강수량 | 해당 시점의 기상 | 현재 실험은 관측값, 배포 시 예보값 필요 |
| 전기요금(계절) | 계절별 요금 관련 값 | 최종 26개 입력에 포함하지 않음 |
| day·d·m | 요일·일·월 정보 | 시간 인덱스에서 필요한 정보 재생성 |
| 공장직원/공장인원 | 가이드북의 생산력 관련 값 | 같은 시간 전력이 계산에 포함되어 제외 |
| 인건비 | 야간·주간 등 비용 배율 | 달력 입력에 포함 |

`15분=100, 30분=120, 45분=160, 60분=140`이라면 평균은 130, 시간 최대수요는 160입니다. 네 값은 누적합이 아닙니다. 센서의 물리 단위와 집계 의미가 확정되지 않았으므로 원자료 숫자를 곧바로 kW·kWh나 전기요금으로 환산하지 않습니다.

## 어떤 근거로 처리했나?

| 대상 | 처리 | 이유와 해석 범위 |
|---|---|---|
| 7월 13일·15일, 48행 | 시간 열이 0–23 범위를 벗어난 행 제외 | 값이 왼쪽으로 한 칸 밀려 원래 시간 정보가 사라진 형태였다. 오른쪽으로 이동해도 정렬 과정에서 바뀐 순서를 확정할 수 없어 시간을 임의로 0–23으로 부여하지 않았다. |
| 8월 28일 18시–29일 10시, 17행 | 공장인원 결측 행 제외 | 생산량과 네 전력값이 모두 0이며 계산식이 정의되지 않는다. 정상 중단인지 기록 문제인지 확인되지 않아 본 실험의 유효 분석 범위에서 제외했다. 일반적인 전력 0 구간을 모두 오류로 간주한다는 뜻은 아니다. |
| 풍속 결측 3개 | 단독 결측은 앞뒤 값 평균, 연속 결측은 앞값 사용 | 주변 관측값으로 보완. 뒤 관측값을 쓰는 보간은 실시간 가용성과 별도로 검토해야 한다. |
| 강수량 결측 1개 | 0 대체 | 분석에서 채택한 가정이며 결측이 항상 무강수라는 증거는 아니다. |
| 삭제한 65시간 | 시간축 재색인 후 NaN 유지 | 7월 12일 다음 행을 7월 14일이 아닌 ‘한 시간 뒤’로 잘못 계산하지 않도록 한다. |
| 반복 전력 패턴 | 유지 | 반복 생산에 의한 정상 패턴 또는 자료 생성 과정의 영향일 수 있으며 반복 원인이 확인되지 않았다. |
| 생산량 0·전력 양수 | 유지 | 대기, 준비, 보조설비 등 여러 가능성이 있어 삭제 근거가 부족하다. |

최종 **유효 전력 기록은 6,103시간**, 계산용 시간축의 길이는 빈 구간을 포함해 **6,168시간**입니다. 핵심 처리 코드는 [`src/preprocess.py`](../src/preprocess.py)에 있습니다.

## 모델 설계로 이어진 관찰

- 낮은 평균 전력 15–30 구간에는 생산량 0인 기록이 많이 나타났다. 대기 상태 후보로 해석하되 실제 설비 상태라고 확정하지 않았다.
- 생산량이 많아지면 전력도 높아지는 경향이 있지만, 생산량 0에서도 높은 전력이 관측된다. 생산 유무와 전력 상태를 같은 라벨로 쓰지 않은 이유다.
- 시간대·요일에 따른 반복 패턴이 있으며, 생산 흐름과 기상을 함께 입력했을 때 예측 성능이 개선되었다.
- 전처리 후 고전력 기준 187을 넘는 315시간 중 229시간(72.7%)은 시간 평균이 187 미만이었다. 따라서 평균보다 시간 내 15분 최댓값에 주목했다.
- 동일 전력 패턴의 반복은 독립적인 사례가 그만큼 많다는 뜻은 아니다. 인과관계나 유의성을 해석할 때 주의가 필요하다.

전체 자료를 사용한 탐색적 분석과 7월 이후 모델 평가는 역할이 다릅니다. 전체 자료에서 찾은 조건을 이용해 모델을 추가 설계했다면, 같은 평가 구간 결과를 완전히 새로운 검증으로 볼 수 없습니다.
