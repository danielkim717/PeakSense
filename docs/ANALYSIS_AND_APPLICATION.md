# 피크 분석과 운영 활용

## 실제 기록과 모델 설명을 함께 확인

데이터 기반 분석은 ‘어떤 조건에서 실제 피크가 자주 나타났는가’를, 모델 기반 분석은 ‘모델이 어떤 정보를 사용해 높게 예측하는가’를 살펴봅니다. 두 관점이 일치하는 조건과 모델이 충분히 반영하지 못한 조건을 구분하기 위해 함께 사용했습니다.

전처리 후 6,103시간 중 분석 기준 187 이상의 피크는 315시간입니다. 최종 발표자료의 주요 조건별 발생률은 다음과 같습니다. 분모는 각 조건에 해당하는 관측 시간이며, 한 조건의 사례가 다른 조건에도 포함될 수 있습니다.

| 관측 조건 | 피크 발생률 | 해석 |
|---|---:|---|
| 08시 | 24.8% | 주간 시작 시간의 높은 부하를 우선 확인 |
| 09–11시 | 17.2% | 오전 생산 시간의 위험 확인 |
| 13–16시 | 11.2% | 오후 생산·재가동 조건 확인 |
| 기온 28℃ 이상 | 28.8% | 더운 날의 부하 확인 |
| 기온 25–28℃ | 11.0% | 기온 구간과 시간대의 결합 확인 |
| 생산량 높은 구간 | 14.4% | 계획량 수준과 피크 관계 확인 |
| 생산량 0 | 1.1% | 생산이 없어도 피크가 발생할 수 있음 |
| 생산 시작 후 1–3시간 | 12.1% | 생산 초기의 전력 변화 확인 |

시각·계절·생산조건은 서로 연결되어 있으므로, 이 수치를 개별 요인의 순수 효과로 해석하지 않습니다. 생산 시작 후의 높은 전력이 누적 기계 부하 때문이라고 단정하지도 않습니다. 고전력 기준과 조건 경계를 바꾸면 비율이 달라집니다.

## 피크 직전의 흐름

직전 시간의 마지막 15분 값과 첫 15분 값의 차이, 생산량이 0에서 양수로 바뀌는 시점, 피크가 몇 시간 이어지는지 등을 확인했습니다. 전체 평균만 보면 시간대 차이가 섞이므로 생산 재시작은 같은 시각끼리 비교했습니다.

이 분석은 최근 전력 상승을 당일 모니터링 신호로 활용할 근거가 됩니다. 전날 예측 시점에는 아직 관측되지 않은 전력이므로, 해당 신호를 전일 예측의 입력으로 미리 사용하지 않습니다.

## 모델이 놓친 조건

SHAP으로 입력의 기여를 살펴보면 시각·요일, 생산계획, 기상이 예측에 반영됩니다. SHAP은 모델의 계산을 설명하며 실제 공장의 인과관계를 증명하지 않습니다.

고전력 구간의 예측오차는 전체보다 크고 과소예측 경향이 있습니다. 오류분석에서 오후 고온 시간에 주목했고, 기온과 시간대의 결합 특성·피크 가중 학습으로 보완하는 실험을 진행했습니다. 발표자료의 미탐지·오경보별 세부 수치는 잔차 시간 경계를 수정한 경보 평가로 다시 확인해야 합니다.

## 운영에 연결하는 절차

| 시점 | 제안한 활용 | 현장에서 확인할 사항 |
|---|---|---|
| 전날 계획 단계 | 다음 날 시간별·15분 전력과 위험시간 확인 | 실제 생산계획과 발행 당시 기상예보 |
| 작업계획 검토 | 08시 시작·13시 재가동 등의 작업 순서와 시점을 검토 | 설비 용량, 최소 연속 운전시간, 작업 순서, 인력, 납기 |
| 당일 운영 | 최근 15분 관측으로 예측 갱신, 상승 흐름 확인 | 경보만으로 설비를 정지하지 않고 원인·운영 영향 확인 |
| 적용 후 | 피크·기준 초과 시간과 생산목표 달성을 함께 평가 | 납기 지연·추가 근무·다른 시간 피크 증가 여부 |

생산량 0인 시간에도 준비 작업이나 보조설비 전력이 있을 수 있으므로, 목적을 확인한 뒤 조정 대상을 정해야 합니다. 공장 전체 전력만으로 특정 설비를 바로 지목하는 자동 제어 기능은 구현하지 않았습니다.

## 부하 분산과 생산일정 실험

**사후 시나리오:** 실제 피크 위치를 알고 08·13시 초과분을 주변 시간으로 분산하거나, 한 시간의 네 15분 값을 고르게 만드는 가정에서 기준 초과 시간 수의 변화를 계산했습니다. 예를 들어 두 가정을 함께 적용한 분석에서는 315시간이 53시간으로 줄었습니다. 실제 피크를 이미 알고 계산한 잠재적 효과이며, 가능한 작업 배치인지와 실제 생산량 유지 여부가 현장에서 검증된 것은 아닙니다. 전력값 합을 유지한다는 가정하에 피크를 분산하는 것이므로 에너지 사용량 자체의 절감과도 구별합니다.

**예측 기반 일정 후보:** 하루 생산목표를 유지하면서 기존 생산 시간에 생산량을 나눠 배치하고 PeakSense로 후보별 예상 전력을 다시 계산합니다. 이 과정은 ‘생산목표량을 주면 반드시 전역 최적인 공정 일정을 제공한다’는 기능보다 제한적인 국소 탐색 실험입니다.

일정 목적함수의 정규화와 반복 이동의 거리 제한에 확인된 문제가 있어, 제출 당시 일정 저감률을 검증된 성과로 내세우지 않습니다. 해당 문제와 실제 공정 제약을 반영한 뒤 재실험해야 합니다. [확인된 개선 과제](LIMITATIONS.md)

## 후속 활용 방향

실제 기상예보, 설비별 전력·가동 기록, 품목별 생산속도, 냉방설비 기록을 추가하면 현장 조건을 더 직접적으로 반영할 수 있습니다. 새로운 기간에서 예측을 검증하고, 현장 담당자가 허용한 작업만 움직이는 제약을 추가해 일정안의 실행 가능성과 피크 저감 효과를 함께 확인하는 것이 다음 단계입니다.
