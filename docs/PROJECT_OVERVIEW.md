# 프로젝트 진행 내용

**제조 생산데이터 기반 전력사용량 예측 및 최대피크 위험조건 분석**
생산계획 기반 가동상태 분리형 전력 최대수요 예측 모델, **PeakSense**

최종 `KAMP 공모전 발표자료.pdf`의 30장 내용을 바탕으로 프로젝트에서 수행한 일을 정리했습니다. 발표자료 파일 자체는 업로드하지 않습니다. 광운대학교 전자통신공학과 강기택·김태우·신여진이 제6회 K-인공지능 제조데이터 분석 경진대회를 위해 진행한 작업입니다.

## 과제 정의

과제는 지정한 미래 시간구간의 전력을 예측하고, 큰 예측오차와 전력 피크가 발생하는 생산조건을 분석하며, 생산일정·설비가동 시점 조정을 통한 저감 방안을 제시하는 것이었습니다.

이에 따라 프로젝트를 **데이터 이해 → 상태별 예측모델 → 피크·오류 분석 → 운영 활용 → 확장 실험**으로 구성했습니다.

## 데이터 이해와 진단

선박 엔진용 볼트·너트 제조공장의 2021년 전력·생산·기상 자료를 살펴보았습니다. 전력은 공장 전체 수준으로 측정되고, 한 시간에 네 개의 15분 전력값이 기록되어 있습니다.

시간 열이 한 칸 밀린 48행과 전력·생산량이 모두 0이며 공장인원이 결측인 17행을 제외했습니다. 삭제한 시간을 빈 시간으로 남겨 시간 순서가 잘못 연결되지 않게 했습니다. 풍속·강수량 결측을 보완하고, 공장인원이 전력에서 계산된 값임을 확인해 입력에서 제외했습니다. 반복 패턴과 생산량 0·전력 양수 기록은 원인을 확정할 수 없어 유지했습니다.

평일과 주말, 오전·오후의 패턴이 다르고 생산량과 전력은 단순 비례하지 않았습니다. 또한 시간 평균만으로는 짧은 피크를 놓칠 수 있어 시간 내 15분 최댓값을 주 예측 대상으로 정했습니다. [데이터와 전처리 상세](DATA.md)

## 예측모델 개발

모델의 입력은 생산계획 15개, 달력 5개, 기상 6개입니다. 현재 실험에서는 제공 생산 기록을 사전 계획으로 간주하고 관측 기상을 예보의 대용으로 사용했습니다.

생산 유무와 높은 전력 상태가 항상 같지 않다는 점에 주목해, 과거 전력으로 높은·낮은 부하 상태 정답을 만들었습니다. 분류기가 미래 상태를 예측하면 상태별 LightGBM 회귀기가 해당 시간의 전력을 예측합니다.

단일 LightGBM·랜덤포레스트·단순 예측 기준과 비교하고, GRU는 공통으로 평가할 수 있는 시간만 사용해 별도로 비교했습니다. 입력을 빼거나 추가하는 실험, 상태 라벨·분기 기준 변경, 확률 가중 결합과 상태별 분기의 비교도 수행했습니다. [모델과 입력 상세](MODEL.md)

## 성능과 안정성 평가

2021.7.1–9.14를 주 단위 11개 구간으로 나누어 과거 자료로 학습한 뒤 미래를 평가했습니다. 1,759시간·74일에서 PeakSense의 시간 최대수요 MAE는 **7.25**, 일 최대수요 MAE는 **8.40**이었습니다. 같은 26개 입력을 사용한 단일 LightGBM 대비 오차가 각각 **24.8%, 31.3%** 작았습니다.

11주 중 10주, 74일 중 54일에서 단일 모델보다 오차가 작았습니다. 당일에는 최근 관측 오차로 보정하는 기능을 추가했고, 8.1–9.14의 15분 앞 MAE는 직전 값 유지 기준 **7.44 → 4.74**로 감소했습니다. [실험 결과](RESULTS.md)

## 피크 조건과 예측오차 분석

실제 기록을 시간대·기온·생산량 등으로 나누는 분석과, 모델의 SHAP 기여값을 확인하는 분석을 함께 수행했습니다. 주간 생산 시간, 특히 08시와 고온·높은 생산량이 겹치는 조건에 주목했습니다.

직전 시간의 전력 상승폭과 생산 재시작 시점, 피크 지속성, 시간 내 피크 위치도 살펴보았습니다. 모델은 높은 피크를 낮게 예측하는 경향이 있었고, 오후 고온 시간대의 설명력을 보완할 필요가 있었습니다. 이 분석은 관측 자료의 관계를 설명하며 특정 설비의 인과적 원인을 확정하지는 않습니다.

## 현장 활용방안

전날에는 위험시간과 생산계획을 함께 확인하고, 조정 가능한 작업의 순서·시점을 검토합니다. 당일에는 15분 관측으로 예측을 갱신하고, 적용 후에는 피크와 함께 목표 생산량·납기·추가 근무 여부를 확인하는 절차를 제안했습니다.

08시 시작과 13시 재가동 전후의 부하 분산, 한 시간 내 15분 부하 균등화 등 사후 시나리오를 분석했습니다. 이어 생산목표를 유지하면서 시간별 배분을 바꾸고 예상 피크를 다시 계산하는 일정 후보 탐색으로 확장했습니다. 설비별 운전시간·작업 순서·납기 제약을 반영한 현장 검토가 필요합니다. [분석과 활용 상세](ANALYSIS_AND_APPLICATION.md)

## 확장 기능과 프로젝트의 의의

오류분석을 반영해 기온×시간 결합 특성과 피크 가중 학습을 추가한 PeakSense+, 적응형 예측구간, 생산일정 권고, 다음 날 피크 미리보기를 실험했습니다.

프로젝트의 의의는 **데이터에서 관찰한 서로 다른 전력 상태를 모델 구조에 반영하고, 예측 입력을 생산계획과 연결해 운영 의사결정을 검토할 수 있게 한 것**입니다. 관측 자료만으로 설비 원인과 현장 저감 효과가 증명되었다는 의미는 아닙니다.

## 자료와 코드의 버전 범위

현재 저장소의 코드는 최종 버전으로 제공된 `PeakSense_code.zip`의 **01~09 단계**입니다. 최신 30장 발표자료에는 **01~10 단계와 통합 예측 엔진**이 소개되어 있지만, 해당 10단계와 통합 엔진의 대응 구현·출력은 제공된 코드 묶음에서 확인되지 않았습니다.

| 자료 범위 | 저장소의 설명 방식 |
|---|---|
| 기존 PeakSense 7.25, 일 최대 8.40, 입력·구조 비교 | 코드·저장 결과와 대조한 주요 결과 |
| 15분 앞 4.74 등 당일 갱신 | 제공 코드의 저장 결과로 제시 |
| PeakSense+·적응형 구간·일정 탐색 | 실험 기능 설명, 검증 과제 별도 표기 |
| 최종 발표의 통합 엔진 15분 MAE 7.67/7.56, 구간 적중률 86.4/87.2/89.8/90.2% | 발표자료에 제시된 추가 결과이며 현재 코드로 재현 확인되지 않음 |

통합 엔진 결과를 기존의 15분 MAE 7.19나 예측구간 적중률과 같은 조건의 지표로 합치지 않았습니다. 대응 코드와 평가 설정을 확보한 후 별도 버전으로 추가할 수 있습니다. 제공 코드에서 확인된 잔차 시간 경계·일정 목적함수 등의 개선 사항은 [LIMITATIONS.md](LIMITATIONS.md)에 기록했습니다.
